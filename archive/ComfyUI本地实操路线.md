## 协作规则（用户 2026-08-08 订正）

1. **AI 执行全部命令，命令全程亮给你看** —— 你盯着每一步，看不懂就喊停
2. **素材 AI 优先找**（模型/参考图），找不到先问你，或上网找经典数据
3. **每课有验收标准**，结果（图/产物）都展示给你，验过才进下一课
4. 报错用 `curl -v` 看真相，AI 排查过程展示给你
5. 每课产出存 `cc/`，进度记到本文件

## 各课详解

### 第 1 课 · 图生图 img2img
- **做什么**：拿一张现有图（猫图）当输入，改它 → 同一场景的新版本
- **核心概念 `denoise`**：重绘强度 0~1
  - `0.2`：基本保留原图，只微调细节
  - `0.6`：明显重新画，但保留大体结构
  - `1.0`：相当于文生图
- **新增节点**：`LoadImage`（读图）+ `VAEEncode`（像素→潜空间）
- **步骤**：启动 server → 猫图放进 input/ → 提交 img2img 工作流 → 先 0.2 后 0.8 各出一张
- **验收**：两张都还是"猫坐长椅"，0.2 接近原图、0.8 明显重画但主体不变

### 第 2 课 · 局部重绘 inpaint
- **核心概念 mask**：黑白图，白=要重画的区域
- **新增节点**：`LoadMask`
- **验收**：椅子换掉，猫不变

### 第 3 课 · API 自动化脚本（强项）
- **产出**：`submit_and_wait.py` —— 读工作流 → 提交 → 轮询 → 下载图
- **验收**：一条命令出图

### 第 4 课 · ControlNet 姿势控制
- **核心概念**：额外条件（骨架）锁住结构；短剧分镜控制关键
- **需下载**：ControlNet OpenPose（ModelScope 找 SD1.5 版）
- **验收**：出图姿态和输入骨架一致

### 第 5 课 · IPAdapter 风格参考
- **需下载**：IPAdapter + CLIP Vision
- **验收**：参考"古风插画"→ 新图也是古风

### 第 6 课 · LoRA 角色/画风
- **需下载**：一个 SD1.5 LoRA
- **验收**：加 LoRA 前后画风明显不同

### 第 7 课 · 高清放大/修复
- **需下载**：Real-ESRGAN
- **验收**：放大后更清晰

### 第 8 课 · 自定义节点
- **验收**：节点面板出现自己的节点且能跑
