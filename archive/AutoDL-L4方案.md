# L4 · 角色 LoRA 训练方案（短剧主角一致性）

> 日期：2026-08-08 ｜ 目标：让短剧主角**跨场景不换脸**
> 前置：已有 comfyui-tzwm 实例（vGPU-32GB，¥1.77/时，SD1.5 环境）

---

## 一、目标与验收

**目标**：训练一个"主角 LoRA"，出图时挂上它，任何场景都是同一张脸/同一角色。

**验收标准**：
- 同一角色在 **5 个不同场景**（古风/现代/夜景/室内/户外）出图
- 脸不漂、风格统一、像"同一个人演的"

---

## 二、原理（大白话 → 算法）

### ① 扩散模型：图像是"从噪声里擦出来的"
```
纯噪声 → 第1步擦一点 → 第2步擦一点 → ... → 第30步 → 清晰图像
   ↑
 每步都被提示词"引导"方向
```
- **大白话**：像把一团马赛克，一步步"恢复"成图片；每步由文字提示词指路
- **算法**：模型预测"这一步该擦掉的噪声 ε"，用 MSE 损失训练：`loss = ||ε - ε_pred||²`
- **关键**：基底模型（FLUX）已经"见过全世界的图"，天生会画"人"

### ② LoRA：不改大模型，只加一个小"偏置"
```
原模型参数 W（冻结不动）
LoRA 增量: ΔW = B × A   （两个小矩阵，几百~几百万参数）
实际用:   W + ΔW   （画图时朝"你的角色"偏一下）
```
- **大白话**：大模型已经会画"所有人"，LoRA 就是给它加个"你的主角长这样"的小便签
- **算法**：低秩分解 —— `ΔW = B·A`，`A` 是 r×d，`B` 是 d×r，`rank r` 决定表达能力（r=8~128）
- **为什么能学角色**：训练时只看你的 20-50 张角色图，让 ΔW 学会"往你的角色特征方向偏"
- **文件小**：LoRA 只有几十 MB（大模型的几百分之一）

### ③ 训练过程：喂图 → 预测噪声 → 对比 → 调 LoRA
```
[角色图] + [噪声] + [时间步 t] → 模型 → 预测噪声
                                        ↓ 和真实噪声对比
                              loss = MSE → 反向传播 → 更新 A,B
循环几千~上万步 → LoRA 学成
```

## 三、输入 / 输出

| 环节 | 输入 | 输出 |
|---|---|---|
| 素材准备 | 20-50 张角色图（多角度/姿势/光线） | 整理好的训练集 |
| 打标 | 训练集图片 | 每张的 caption（描述文本）|
| 训练 | 图 + caption + 基底模型（FLUX） | **LoRA 文件（.safetensors）** |
| 推理测试 | LoRA + 提示词 | 出图，验证一致性 |

## 四、过程（分步规划）

### Step 0 · 扩数据盘
- 现状：只剩 **2.9G**，FLUX（~12GB）放不下
- 动作：AutoDL 控制台扩容数据盘（或清掉 Wan 模型腾空间）
- 成本：扩容 ¥几块

### Step 1 · 下 FLUX 基底模型
- 模型：FLUX.1-dev（12B，fp8 ~12GB）或 FLUX.2-Klein（更小更快）
- 来源：hf-mirror（实测 272-382 MB/s，几分钟）
- 位置：`/root/autodl-tmp/ComfyUI/models/checkpoints/`

### Step 2 · 准备角色素材（用户侧）
- 主角图 **20-50 张**：不同角度、表情、光线、服装
- 来源：你收集的真人照 / AI 生成的角色设定图 / 已有素材
- 质量 > 数量：多角度高清胜过 200 张糊图

### Step 3 · 打标（caption）
- 每张图配一句描述（发色/服装/场景/动作）
- 工具：BLIP / WD-Tagger（ComfyUI 插件）自动打标 + 手动精修

### Step 4 · 训练 LoRA
- 工具三选一（ComfyUI 内训练）：
  | 后端 | 能训 | 显存 |
  |---|---|---|
  | **Musubi Tuner** | FLUX Klein 4B/9B | ~13GB ✅ 最适合 vGPU-32G |
  | **AI-Toolkit** | FLUX.1-dev / Z-Image | 高 |
  | **kohya sd-scripts** | SDXL / SD1.5 / FLUX | 成熟 |
- 关键超参：`rank`(8-64)、`learning rate`(~1e-4)、`steps`(1000-3000)
- 耗时：1-3 小时 × ¥1.77/时 ≈ ¥2-5

### Step 5 · 应用测试
- ComfyUI 工作流挂 LoRA 节点 + 触发词（如 `ana`）
- 出 5 个场景测试图 → 看脸稳不稳

### Step 6 · 迭代优化
- 脸漂 → 加训练步数/调 rank；糊 → 换基底/加素材
- 稳定后：**LoRA + InstantID 锁脸 + IPAdapter 统一风格**（三件套）
