# ComfyUI 云端出图 · 完整命令复盘（L3）

环境：tzwm 整合包 / vGPU-32GB / 隧道 localhost:8190

## ① 搭隧道（把云端 ComfyUI 搬到本地 8190 端口）
```bash
ssh -fN -L 8190:127.0.0.1:6006 -p <实例SSH端口> root@<实例SSH域名>
# -fN 后台运行不执行命令 | -L 本地端口:远程地址:远程端口
```

## ② 下载模型（hf-mirror 国内镜像）
```bash
cd /root/autodl-tmp/ComfyUI/models/checkpoints
wget -c 'https://hf-mirror.com/stable-diffusion-v1-5/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.safetensors' -O v1-5-pruned-emaonly.safetensors
# -c 断点续传 | -O 输出文件名
```

## ③ 确认后端活着 + 模型被识别
```bash
curl http://127.0.0.1:8190/system_stats                 # 后端状态
curl http://127.0.0.1:8190/object_info/CheckpointLoaderSimple  # 列出模型
```

## ④ 提交生成（核心：POST 工作流到 /prompt）
```bash
curl -X POST http://127.0.0.1:8190/prompt \
  -H "Content-Type: application/json" \
  -d '{"prompt": { 工作流JSON }}'
# 返回 prompt_id，记下来用于查结果
```

## ⑤ 轮询结果（等生成完成）
```bash
curl "http://127.0.0.1:8190/history/{prompt_id}"
# 看 outputs 里的 images 字段 → 拿到文件名
```

## ⑥ 取图（下载到本地）
```bash
curl "http://127.0.0.1:8190/view?filename=scene_xxx.png&type=output" -o 本地文件名.png
```

## ⑦ 批量传回本地（SCP）
```bash
scp -P <实例SSH端口> root@<实例SSH域名>:/root/autodl-tmp/ComfyUI/output/*.png /本地/目录/
```

## 核心：SD1.5 文生图工作流 JSON（模板）
```json
{
  "4": {"class_type":"CheckpointLoaderSimple","inputs":{"ckpt_name":"v1-5-pruned-emaonly.safetensors"}},
  "6": {"class_type":"CLIPTextEncode","inputs":{"text":"正向提示词","clip":["4",1]}},
  "7": {"class_type":"CLIPTextEncode","inputs":{"text":"负向提示词","clip":["4",1]}},
  "5": {"class_type":"EmptyLatentImage","inputs":{"width":512,"height":512,"batch_size":1}},
  "3": {"class_type":"KSampler","inputs":{"seed":123,"steps":22,"cfg":7,
        "sampler_name":"euler","scheduler":"normal","denoise":1.0,
        "model":["4",0],"positive":["6",0],"negative":["7",0],"latent_image":["5",0]}},
  "8": {"class_type":"VAEDecode","inputs":{"samples":["3",0],"vae":["4",2]}},
  "9": {"class_type":"SaveImage","inputs":{"filename_prefix":"输出名前缀","images":["8",0]}}
}
```
节点连接逻辑：
- 4 CheckpointLoader → 输出 model[0]/clip[1]/vae[2]
- 6,7 CLIPTextEncode → 正向/负向词（用 clip）
- 5 EmptyLatentImage → 画布
- 3 KSampler → 采样（用 model + 两个词 + 画布）
- 8 VAEDecode → 解码（用 vae）
- 9 SaveImage → 保存
